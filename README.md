# Retro Terminal Piano

A lightweight, zero-dependency interactive terminal piano built with Python and the `curses` library. Perfect for a quick musical distraction while working in the command line.

## ⚠️ System Requirements
* **Operating System:** macOS ONLY (Uses the native Mac `afplay` system utility for audio playback).
* **Python Version:** Python 3.x

## 🚀 How to Run
1. Open your Mac Terminal.
2. Navigate to the folder containing the script.
3. Run the following command:
   ```bash
   python3 retro_piano.py
   ```

## 🎹 Keyboard Controls
* **White Keys:** `A` `S` `D` `F` `G` `H` `J` `K` (C4 to C5)
* **Black Keys:** `W` `E` `T` `Y` `U` (Sharps and Flats)
* **Quit:** Press `Q` to exit smoothly back to your shell prompt.
